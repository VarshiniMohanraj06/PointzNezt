# PointzNest – Hotel Customer Rewards Platform

## Project Description
PointzNest is a hotel customer rewards and loyalty management platform that helps hotels improve customer engagement through reward points.

## Technologies Used
- Frontend: Astro, HTML, CSS, JavaScript, TypeScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Algorithm: Apriori Algorithm

## Key Features
- Customer rewards management
- Earn and redeem reward points
- Menu combination analysis using Apriori algorithm
- Customer and hotel owner dashboards

## Project Type
Second-Year Team Mini Project
